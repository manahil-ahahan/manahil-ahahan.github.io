# موقع منتوجات مناحل احاحان

الموقع الرسمي لـ **منتوجات مناحل احاحان**: العسل بجميع أنواعه ومشتقات الخلية. يعرض المنتوجات والخدمات والصور والريلز، ويستقبل الطلبات عبر واتساب.

موقع ثابت (HTML + CSS + JavaScript) لا يحتاج خادماً ولا قاعدة بيانات. يُنشر مجاناً على **GitHub Pages**.

## تعديل المحتوى

كل المعلومات في ملف واحد: `js/data.js`

| ما تريد تغييره | أين |
|---|---|
| رقم واتساب، المدينة، روابط إنستغرام وتيك توك... | `window.SITE` (بعد وضع الرقم الحقيقي، غيّر `phoneIsSample` إلى `false`) |
| المنتوجات (الاسم، الوصف، لون العسل في الرسم) | `window.PRODUCTS` |
| الخدمات | `window.SERVICES` |
| الصور | ضع الصور في `images/gallery/` ثم أضفها إلى `window.GALLERY` |
| الريلز | ضع الفيديوهات (MP4) في `videos/` ثم أضفها إلى `window.REELS` |

نصائح للملفات:
- **الصور:** JPG بعرض حوالي 1200px، وأقل من 300KB لكل صورة.
- **الفيديو:** MP4 بمقاس 9:16، وأقل من 20MB لكل فيديو.

## البنية

```
index.html          الصفحة
css/style.css       التصميم (ألوان العسل، خط Reem Kufi للعناوين وTajawal للنص)
js/data.js          المحتوى القابل للتعديل
js/main.js          رسم الصفحة، رسومات المنتوجات، نموذج الطلب عبر واتساب
assets/logo.svg     الشعار المبسّط (سداسية + نحلة) للرأس والأيقونة
assets/logo-original.jpg  الشعار الأصلي
images/gallery/     صور المنحل
videos/             الريلز
```

## النشر على GitHub Pages
1. يجب أن يكون المستودع **Public**.
2. افتح **Settings** ← **Pages**.
3. في **Source** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، ثم **Save**.
4. بعد دقيقة أو دقيقتين يصبح الموقع متاحاً على:
   `https://tinzeftesoulaiman-dev.github.io/اسم-المستودع/`
